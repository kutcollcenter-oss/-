# Юрта — новостройки Бишкека в рассрочку

Карта Бишкека с 3D-моделями жилых комплексов. Гость выбирает ЖК → блок → этаж → квартиру и сразу видит условия рассрочки. На главной есть подбор по бюджету (взнос → платёж в месяц). Живой чат с менеджером, уведомления сотрудникам, админка сотрудников.

## Запуск

Нужен Node.js 18+. Внешние библиотеки не требуются.

```bash
node serve.js
```

Сайт откроется на http://localhost:5180 (порт меняется переменной `PORT`).

При первом запуске создаётся администратор. Логин и пароль лежат в `data/admin-password.txt`. После входа смените пароль и удалите этот файл.

## Где что лежит

| Путь | Что это |
|---|---|
| `serve.js` | сервер: статика, вход сотрудников, чаты (SSE), админка |
| `site/js/data.js` | ЖК, блоки, планировки, цены, рассрочка — **новые объекты добавлять сюда** |
| `site/js/model3d.js` | 3D-модели (three.js поверх MapLibre) |
| `site/js/app.js` | карта, панель, подбор по бюджету, калькулятор |
| `site/js/chat.js` | чат гостя и пульт сотрудника |
| `site/img/` | рендеры и планировки из презентаций |
| `data/` | база (переписка, сотрудники) — не в git |
