API для застройщиков

Через API ваша система (CRM, 1С, шахматка, сайт) держит статусы квартир на «Объектах» актуальными и получает брони, которые клиенты делают у нас на сайте.

Доступ выдаём каждой компании отдельно: логин и пароль привязаны к вашим ЖК. Чужие ЖК через ваш доступ не видны и не меняются. Пароль храните на сервере, не в коде сайта.

Как работает бронь

  1. Клиент выбирает свободную квартиру на нашем сайте и оставляет имя и телефон.
  2. Квартира сразу получает статус booked (бронь) на 24 часа. Вам приходит уведомление booking.created с контактами клиента.
  3. Менеджер связывается с клиентом и в течение 24 часов:
    • подтверждает продажу: confirm → статус sold;
    • или продлевает бронь: extend, до 72 часов за раз;
    • или отменяет: cancel → статус free.
  4. Если за 24 часа ничего не сделано, бронь снимается автоматически: квартира снова free, вам приходит booking.expired.

Адрес и формат

Базовый адрес: https://ваш-адрес/api/partner. Все запросы и ответы — JSON (Content-Type: application/json), время — ISO 8601 (UTC).

Ключ квартиры

Квартира обозначается ключом блок-номер: например Б-37 или 3-64. Номер — сквозной номер квартиры в блоке, как в ваших документах. Перед запуском сверяем нумерацию с вашей шахматкой.

Статусы

СтатусЗначение
freeСвободна — клиент может забронировать
bookedБронь
soldПродана

Квартиры, которых нет в ваших данных, считаются свободными.

1. Получить токен

POST/api/partner/token

{ "login": "avangard", "password": "ваш пароль" }

Ответ:

{ "token": "3f9c…", "expiresIn": 86400, "projects": ["zhk-avangard"] }

Токен действует 24 часа. Передавайте его в каждом запросе заголовком Authorization: Bearer 3f9c…. Когда токен истечёт, придёт ответ 401: получите новый токен тем же запросом. Не больше 10 попыток входа за 10 минут.

2. Обновить статусы

POST/api/partner/statuses — можно передать сразу всю шахматку, до 5000 квартир за раз.

{
  "project": "zhk-avangard",
  "items": [
    { "key": "Б-37", "status": "sold" },
    { "key": "Б-38", "status": "booked" },
    { "key": "А-12", "status": "free" }
  ]
}

Ответ: { "updated": 3, "rejected": [] }. Если поставить sold или free квартире, на которую есть активная бронь с сайта, бронь закроется сама.

Статусы на сайте обновляются у посетителей в течение минуты.

3. Посмотреть статусы

GET/api/partner/statuses?project=zhk-avangard

{ "project": "zhk-avangard", "statuses": { "Б-37": { "st": "sold", "at": 1763712000000, "by": "СК Авангард" } } }

4. Брони

GET/api/partner/bookings?project=zhk-avangard&state=active

state: active (ждёт решения), sold, cancelled, expired. Без параметров — все брони по вашим ЖК.

{ "bookings": [ {
  "id": "8c1e…", "project": "zhk-avangard", "key": "Б-38",
  "name": "Айгерим", "phone": "+996 555 12 34 56",
  "info": "5 этаж, 61,5 м², взнос 880 000 сом, 59 мес.",
  "state": "active",
  "createdAt": "2026-11-21T08:10:00.000Z", "expiresAt": "2026-11-22T08:10:00.000Z"
} ] }

Подтвердить, продлить или отменить

POST/api/partner/bookings/{id}

{ "action": "confirm" }              // продано → статус sold
{ "action": "extend", "hours": 24 }  // продлить бронь (1–72 ч)
{ "action": "cancel" }               // отменить → статус free

5. Уведомления (webhook) — по желанию

Пришлите нам адрес https://…, и мы будем отправлять на него POST при каждом событии, чтобы не опрашивать API:

{ "event": "booking.created", "project": "zhk-avangard", "at": "2026-11-21T08:10:00.000Z",
  "booking": { "id": "8c1e…", "key": "Б-38", "name": "Айгерим", "phone": "+996 …", "expiresAt": "…" } }

События: booking.created — новая бронь; booking.expired — бронь не подтвердили за 24 часа, квартира снова свободна (в теле "status": "free", поставьте этот статус у себя).

Проверка подлинности: заголовок X-Objekty-Signature — это HMAC-SHA256 тела запроса с вашим секретом подписи (его выдаём вместе с паролем).

// Node.js
const sig = crypto.createHmac('sha256', SECRET).update(rawBody).digest('hex');
if (sig !== req.headers['x-objekty-signature']) return res.status(401).end();

Пример: curl

TOKEN=$(curl -s -X POST BASE/token -H 'Content-Type: application/json' \
  -d '{"login":"avangard","password":"…"}' | jq -r .token)

curl -s -X POST BASE/statuses -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"project":"zhk-avangard","items":[{"key":"Б-37","status":"sold"}]}'

Ошибки

КодПричина
400Неверный формат запроса или действия
401Нет токена, токен истёк, неверный логин или пароль
403Нет доступа к этому ЖК
404Бронь не найдена
409Бронь уже закрыта (продана, отменена или снята)
429Слишком много попыток входа — подождите 10 минут
