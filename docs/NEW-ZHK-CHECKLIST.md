# Новый ЖК на «Объектах» — чек-лист

Каждый новый ЖК должен получить **всё то же**, что есть у Altay Gold, Altay Ordo и Алтай Плюс.
Ни один ЖК не должен быть «беднее» других. Идём по списку и отмечаем каждый пункт.

## 1. Исходники от застройщика
- [ ] АР (рабочий проект): планы этажей, план кровли, листы «Фасад по осям …» с ведомостью отделки (RAL), разрезы с отметками этажей
- [ ] Ситуационная схема или генплан: расстановка корпусов, дороги, парковки, площадки
- [ ] Презентация с рендерами: только для фото в галерее и общего настроения
- [ ] Цены (сом/м², по блокам, если разные), взнос, срок рассрочки, срок сдачи
- [ ] Нумерация квартир застройщика — сверить с нашим ключом «блок-номер»

**Правило:** размеры, контуры, цвета, окна и этажность берём **из АР**, а не из рендеров.

## 2. Данные (site/js/data.js)
- [ ] Запись проекта: id, название, застройщик, адрес, район, marker и origin (сверить со спутником), rotation, стиль
- [ ] Цены, взнос, рассрочка, срок сдачи, этапы сдачи (handover)
- [ ] Этажи: firstResidentialFloor, residentialBase, floorHeight, ceiling, коммерция (podiumLabel)
- [ ] Планировки: картинка плана и hd-версия с калибровкой (hdK, hdMpp), квартиры (poly, rooms, area, euro), подписи площадей, кухни и санузлы (wet), балконы
- [ ] **Точный контур корпуса по плану кровли АР** (axesM и outlineM в метрах), с выступами и нишами, без плоских сторон
- [ ] Глухие стороны (blank) — по листам фасадов
- [ ] planUp: куда смотрит вход, сверить с генпланом
- [ ] Генплан: участок (plot), поверхности (газоны, тротуары, проезды), парковки, площадки во дворе (yard), въезды в паркинг (ramps / downRamps с крышей), паркинг и детсад (volumes)
- [ ] Фото-галерея (renders), описание (about), stats

## 3. 3D — всё, что есть у других ЖК
- [ ] Фасад по ведомости отделки: свой texXxx() с цветами RAL, размерами окон (например 1800 мм) и корзинами кондиционеров
- [ ] Окна — только там, где за стеной квартира; угловые окна не закрыты декором
- [ ] Объёмные корзины кондиционеров (BASKET в model3d.js)
- [ ] Стекло с отражениями: маска стекла в текстуре (markGlass)
- [ ] Ночные окна и витрины: светятся (emissive из текстуры)
- [ ] Тени по умолчанию, режим «Солнце в квартире»
- [ ] Деревья по газонам и аллея вдоль участка (autoTrees): нет деревьев на дорогах, крышах и въездах
- [ ] Фонари вдоль участка, люди у площадок, машины на проездах, вывески над витринами
- [ ] Кровля (ROOF_STYLE), парапет, выходы на кровлю
- [ ] Коммерция первого этажа (если есть) и вывески
- [ ] Вид на горы и спутник: проверить, что ЖК хорошо смотрится на спутнике MapTiler

## 4. Функции сайта
- [ ] 3D-тур по **каждой** квартире (по hd-плану АР; проверить площади)
- [ ] Вид из окна (каждый этаж, все стороны)
- [ ] «Солнце в квартире»
- [ ] Калькулятор рассрочки, расчёт-ссылка для WhatsApp или PDF
- [ ] Подбор по бюджету: ЖК участвует, квартиры подсвечиваются
- [ ] Избранное и сравнение
- [ ] Ход стройки (progress)
- [ ] Прогулка по коммерции или паркингу (walk), если есть планы
- [ ] Чат: просмотр квартиры виден менеджеру

## 5. Статусы и брони (API застройщика)
- [ ] Создать доступ к API: пульт → 🏗 «Застройщики · API» → компания, логин, ЖК (и webhook, если есть)
- [ ] Отдать застройщику логин, пароль, секрет подписи и ссылку на /api-docs.html
- [ ] Сверить ключи квартир «блок-номер» с их шахматкой
- [ ] После первой выгрузки статусов выключить demoStatuses
- [ ] Проверить: бронь с сайта → у застройщика `booking.created`; без подтверждения через 24 ч → квартира снова свободна

## 6. Проверка перед выкладкой
- [ ] Снимки: сверху, вблизи фасада, с каждой стороны, ночь, спутник, телефон
- [ ] Сравнить 3D с листами фасадов АР и генпланом
- [ ] smoke-тест всех страниц без ошибок; телефон: шторка, маркеры, кнопки не перекрываются
- [ ] git push, затем `objekty-update` на сервере
